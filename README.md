# SeunFinance — Global Money Toolkit

A professional, fast, AdSense-ready finance platform built by **seunweb05**. 
For currency conversion, loan/mortgage calculation, and crypto tracking.

🔗 **Live Site:** https://seunfinance.web.app/
💻 **GitHub:** seunweb05/SeunFinance

### 🚀 Included Tools
1.  Currency Converter - 160+ world currencies
2.  Mortgage Calculator
3.  Loan Calculator
4.  Salary Calculator
5.  Tax Estimator
6.  Fuel / Gas Cost Calculator
7.  Crypto Tracker (BTC, ETH, etc)
8.  All Live Rates Table

### 🛠️ Stack
- HTML5, CSS3, Vanilla JavaScript
- ExchangeRate-API - for FX rates
- CoinGecko API - for crypto prices
- Firebase Hosting - HTTPS + CDN
